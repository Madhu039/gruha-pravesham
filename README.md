# Gruha Pravesham Digital Invitation

## Run
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local Vite URL shown in the terminal.

## Customize
Edit `src/main.jsx`, especially the `CONFIG` object:
- `familyName`
- `date`
- `displayDate`
- `muhurtham`
- `lunch`
- `venue`
- `address`
- `mapsUrl`
- `phone`

Replace the three gallery placeholders in `src/main.jsx` with `<img>` elements pointing to your own photos.

For devotional background music, add `public/music.mp3` and connect it to the music state/button in `src/main.jsx`.
